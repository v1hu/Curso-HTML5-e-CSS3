Capítulo 11 Aula 1 – Imagens Dinâmicas

Mídias em HTML5

Tente abrir esse site em varios dispositivos diferentes ou simplismente aumente e diminua o tamanho do seu navegador

tags usadas (<picture> <img src="imagens/foto-G-ex11.png" alt="imagem flexível" </picture>)

dentro de ( ) entra a tag (< source > media="(min-width:1050px)" srcset="imagens/foto-M-ex11.png" type="imagens/png") - os valores de width podem ser , min ou max-width.

< picture> < source media="(max-width: 1000px)" srcset="imagens/foto-M-ex11.png" type="image/png">

(" < img src="imagens/foto-G-ex11.png" alt="imagem flexível"> ")

LARGURA = max-width:1050px, por padrao vai carregar, mas se seu navegador tiver menos de 1000px, mobiles etc, o tamanho max sendo 1050px, o sistema vai carregar o parametro source set > srcset="imagens/foto-M-ex11.png, com type="image/png", sempre seguir a sequencia, dentro da tag picture de baixo para cima, a imagem original, acima soucer media type dos tamanhos menores, resultado completo abaixo :

< picture> < source media="(max-width: 750px )" srcset="imagens/foto-p-ex11.png" type="image/png"> < source media="(max-width: 1050px)" srcset="imagens/foto-M-ex11.png" type="image/png"> < img src="imagens/foto-G-ex11.png" alt="imagem flexível"> < /picture>

Reproduzindo aúdios em HTML5

MP3

< audio src="MP3" controls > < /audio> = MP3, wv, ogg - versao meio limitada, , (controls) mostra os controles no site exemplo abaixo

modo 2 - < audio preload="auto" autoplay controls> < source src="imagens/audio-ex11.mp3" type="audio/mpeg"> < /audio > // o (autoplay) faz da play ao entrar, (preload="auto") faz o site carregar o audio todo mesmo ante de tocar, se tiver 'none', vai carregar so após o play
