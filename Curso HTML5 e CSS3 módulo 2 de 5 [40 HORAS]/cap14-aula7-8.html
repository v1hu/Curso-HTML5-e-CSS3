7 - Usando fontes externas baixadas

Entrar no site de baixar font, baixar os arquivos LOVE.OTF / LOVE.TTF, copia os dois arquivos e joga dentro da pastas com o arquivo html, uso do tipo de arquivo depende do navegador, usar os 2 melhor método.

Tipos de Format: opentype(.otf), truetype(.ttf), embedded-opentype, truetype-aat (apple advanced typografy), svg.

<style>

@font-face {

    font-family: 'Love';
    src: url('fonts/love larry.otf') format('opentype'), url('fonts/love larry.ttf') format('truetype');
    font-weight: normal;
    font-style: normal;
}

h1 {
    font-family: 'Love', times, serif;
    font-size: 3em;
    font-weihht: normal;
}

</style>
