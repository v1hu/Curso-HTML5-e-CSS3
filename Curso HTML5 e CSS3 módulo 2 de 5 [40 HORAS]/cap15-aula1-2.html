1 - Seletores Personalizados: Usando o id(#) com CSS

id(#) = Identificador de Elementos

Usando a tag <link> rel="stylesheet" href="style.css" para acessar os estilos externos:

HTML5: <h1 id="principal"> TITULO PRINCIPAL </h1>

CSS3:

@charset "UTF-8"

body {
    backgroundcolor: green;
    font-family: Arial;
}

h1 {
    backgroundcolor: green2;
}

#principal {
    text-align: center; (identificou o titulo para dar uma caracteristica única, usando a # do Id.)
}

h2 {
    backgroundcolor: green3;
}

OBS: Dentro de um doc HTML5 só se pode ter um elemento "Id(#)". /Regra W3C

2 - As diferenças entre id(#) e class(.)

class(.) = Classificar os Elementos (OBS: Nome das classes pela funcionalidade)

<span> </span> = Com essa tag da para selecionar algo dentro do texto e atribuir a personalizaçao de uma class="", exemplo:

<p> <span class"basico"> TEXTO PERSONALIZADO </span></p>

Usando a tag <link> rel="stylesheet" href="style.css" para acessar os estilos externos:

HTML5:

<h1 class="basico"> TITULO BASICO </h1>

<h1 class="intermediario"> TITULO INTERMEDIARIO </h1>

<h1 class="avancado"> TITULO AVANÇADO </h1>

<h1 class="destaque"> DESTAQUE </h1>


Duas classes podem ser usadas juntas ao mesmo tempo nesse caso vai ter um titulo e um fundo em destaque:

<h1 class="avancado destaque"> TITULO AVANÇADO COM DESTAQUE </h1>


CSS3:

@charset "UTF-8"

body {
    color: black;
    font-family: Arial;
}

h1 {
    color: black; (CORES DE TITULO PADRAO BASE)
}

.basico {
    color: green; (CORES DE TITULO DIFERENTES)
}

.intermediario {
    color: red; (CORES DE TITULO DIFERENTES)
}

.avancado {
    color: blue; (CORES DE TITULO DIFERENTES)
}

.destaque {
    backgroundcolor: red; (COR DE FUNDO PERSONALIZADO)
}

class:"" = Tambem faz a config personalizada, quando eu quero aplicar a mesma config em varios elementos.
