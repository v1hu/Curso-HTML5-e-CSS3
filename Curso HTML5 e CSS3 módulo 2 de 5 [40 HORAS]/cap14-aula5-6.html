5 - Peso, estilo e shorthand font

weight = peso // width = largura // heigth = altura

Familia da fonte (font-family:): familia da fonte, exemplo, Arial, 'Courrier News'

Peso da Fonte (font-weight:) : Fonte mais gorda ou magra, exemplos de variaçoes tipografica, lighter, normal, bold, bolder, exemplos de variaçoes numéricas, indo de 100 até 900, 100 = lighter, 400 = normal

Modo Padrao:

h1 {

    font-style: italic;
    font-weight: bolder;
    font-size: 3em;
    font-family: 'Work Sans', sans-serif
}

Modo Padrao:

h1 {
    font-style: italic;
    font-weight: bolder;
    font-size: 3em;
    font-family: 'Work Sans', sans-serif
}

Tamanho da Fonte (font-size:): tamanho da fonte, exemplo, 3em

Estilo (font-style:): Fonte em itálico, normal, oblique

Texto Decorado (text-decoration:): Fonte com underline

Shorthand: Uma maozinha, atalho, simplificar a vida, no caso da font, seria shorthand font, onde se vai condensar todas as configuraçoes da font e uma ordem que deve ser seguida:

Modo Padrao:

h1 {

    font-style: italic;
    font-weight: bolder;
    font-size: 3em;
    font-family: 'Work Sans', sans-serif
}

Modo shorthand:

font: italic bolder 3em 'Work Sans', sans-serif;

6 - Usando Google Fonts: usando fontes externas

Entrar no site do google fonts, e copiar o embed e botar dentro da tag style e antes da tag body.

<style>

@import url('google.fonts.com/Work-Sans');

@import url('google.fonts.com/Kaushan-Script');

body {
    font-family: 'Work Sans', Arial, sans-serif;
    font-size: 16px;
    color: black;
}
h1 {
    font-family: 'Kaushan-Script',sans-serif;
    font-size: 16px;
    color: black;
}
</style>
