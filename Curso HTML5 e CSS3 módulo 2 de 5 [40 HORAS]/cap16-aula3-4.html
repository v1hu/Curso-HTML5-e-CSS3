3 - Modelo de Caixas na prática (Pt.2)

ANATOMIA DE UMA CAIXA:

heigHT = altura

widTH = largura/espessura

border = borda

padding = acolchoamento, preenchimento é a separaçao borda da caixa para dentro

margin = margem é a separaçao externa da borda da caixa para fora

outline = contorno ou traçado fora do elemento entre a borda e margin, só que dentro da margin

display:inline; = para transformar block em inline, usar o display inline(n consegue configurar altura e largura)

display:block; = para transformar inline em block, usar o display block (n consegue configurar altura e largura)

display:inline-block; = continua sendo inline, mas configura altura e largura



ORDEM = SEMPRE COMEÇAO A ORDEM NO SENTIDO DO RELÓGIO:

TOP - RIGHT - BOTTOM - LEFT

margin: auto; centraliza o conteudo independente do tamanho da tela

(exemplo box-level)

h1 {

background-color: blue;

height: 300px; (*ALTURA*)

width: 300px; (*LARGURA*)


border-width: 10px; (*LARGURA DA BORDA*)

border-style: solid;

border-color: blue; (*COR DA BORDA*)


padding-top: 10px; (acolchoamento superior (TOP))

padding-right: 10px; (acolchoamento direita (right))

padding-bottom: 10px; (acolchoamento inferior (bottom))

padding-left: 10px; (acolchoamento esquerda (left))


margin-top: 10px; (margem superior (TOP))

margin-right: 10px; (margem direita (right))

margin-bottom: 10px; (margem inferior (bottom))

margin-left: 10px; (margem esquerda (left))


outline-width: 5px; (largura do outline)

outline-style: dashed; (trecejado)

outline-color: black; (cor do tracejado)

}

(shorthands) Simplificando códigos CSS3:


border: 10px solid blue ; (*SHORTHAND BORDER*)


padding:10px; (*SHORTHAND PADDING*)


10px 10px 10px 10px, se todos os tamanhos forem iguais igual nesse exemplo, so usar 1x o 10px

*** se dois valores forem igual, tipo 10px 20px, ou seja top, e direita, ele vai dar para o bottom o valor de top e o da direita vai ser igual o da esquerda.


margin:10px; = (10px 10px 10px 10px;) (*SHORTHAND BORDER*)


margin: 20px 20px 40px 20px ; (*SHORTHAND MARGIN*)


margin: 20px auto 40px auto ; (*SHORTHAND MARGIN2 - direita e esquerda centralizado*)


outline: 5px (largura) dashed black ; (*SHORTHAND OUTLINE*)
