3 - Pseudo-classes em CSS

div(.div) = Ela é um elemento de divisão/agrupamento de conteúdo, normalmente usado como contêiner.

:hover(:) = pseudo classes sao palavras que definem estados de elementos dentro do HTML.

Usando a tag <link> rel="stylesheet" href="style.css" para acessar os estilos externos:

HTML5: <div id="EXEMPLO-01"> EXEMPLO-01 </div>

CSS3: Pseudo-classes em CSS

@charset "UTF-8"

div {

display: block; (DEIXA UM DO LADO DO OUTRO)

border: 1px solid black;

background-color: green;

text-align: center;

height: 200px; (*ALTURA*)

width: 200px; (*LARGURA*)

}

#EXEMPLO-01 {

background-color: blue; (ID NORMAL)

}

div:hover { - (QUANDO PASSA O MOUSE// div:hover > pseudo class)

background-color: yellow;

}

Pseudo-classes(:) = Tem que estar relacionado ao uma classe (class) ou elemento (id), estão relacionadas ao estado de um elemento ou a condições específicas.

hover(:) = aplicado no exemplo ao elemento "div", é uma pseudo-classe que aplica estilos quando o ponteiro está sobre o elemento, (div:hover > p), o ">" é o combinador de filho direto.

CSS3: Pseudo-classes em CSS

body {

font-family: Arial

}

a {

color: red; (cor do link)

text-decoration none; (tirar sublinhados de links)

font-weight bold; (negrito)

}

a:visited {

color: darkred; (quando os sites ja foram visitados)

}

a:hover {

color: black; (passa o mouse fica preto)

text-decoration: underlina; (sublinhado quando passa o mouse)

}

a:active {

color: yellow; (quando clica no link fica amarelo)

}
