Capítulo 12 Aula 1 – Estilos CSS inline

CSS3 Inline

No cap 8 , aprendemos que no HTML5 é focado em semantica, significado, na diferenciaçao nítida dos capitulos e titulos escritos(h1 / h2), nao na forma, fazer o conteudo ter sentido.

O CSS3, as folhas de estilo, vao permitir voce dar um estilo a sua pagina e podem ser aplicadas de tres formas:

    Inline
    Menos usado, aplica as cores localmente no código , escreve o codigo CSS dentro do codigo HTML:
    < body style="background-color:lightskyblue; font-family: Arial, Helvetica, sans-serif;text-align: justify;" < / body >

Capitulo 12 aula 2 - Estilos CSS Internos ou locais

CSS3 INTERNOS

Esse modo abrimos uma tag < style > < / style > logo abaixo de title, dentro dessa tag tudo que for escrito vai ser considerado CSS, esse método é bom, mas o CSS3 externo é o melhor.

    Internos
    Estilo baseado em seletores "{}", vamos usar a tag < BODY > < / BODY > de exemplo:
      < style >
      < body {
      background-color:brown;
      font-family: Arial, Helvetica;
      font-size: 20px;
      }

      h1 {
      color:blue;
      background-color:white;
      }

      h2 {
      color:red;
      }

      p {
      text-aliagn: justify
      }
      < style / >

Capitulo 12 aula 3 - Estilos CSS Externos

CSS3 Externos

A aplicaçao do CSS3 fica em outro arquivo.

    Externos
    chamar usando funçao (link:css):
    < link rel="stylesheet" href="style.css">
    usar regra: @charset"UTF-8" no arquivo que vai ser criado de css clicando em style.css, caso o arquivo nao exista.
