7 - Detectando fontes dentro de imagens

Três ferramentas são exploradas ao longo da aula: WhatTheFont (MyFonts), Font Squirrel e WhatFontIs.

WhatTheFont (MyFonts): www.myfonts.com.

Font Squirrel: www.fontsquirrel.com.

WhatFontIs: www.whatfontis.com- site com possivel maior inteligencia em distinguir fontes em uma imagem.

8 - Alinhamento de textos com CSS

Tipos de Alinhamento: Left (esquerda,padrao), right (direita), center (centralizado), justify (justificado)

<style>

body {
    font: normal, 16px, Arial, Verdana, serif;
    text-align: left; (padrao, alinhado a esquerda)
}

h1 {
    text-align: center; (centralizado)
}

h2 {
    text-align: right; (alinhado a direita)
}

p {
    text-align: justify; (justificado, alinhado a direita e a esquerda )
    text-indent: 30px; (espaço paragrafo)
}

</style>
